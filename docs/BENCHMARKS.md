# Reproducible benchmark protocol

- Compare identical world save copies, route, camera movement, view distance, hardware and JVM.
- At least five repeated runs with the scheduler OFF and ON, same start state and warm-up.
- Use external frame-time capture. Report average FPS, p95/p99 frame time, 1% low FPS.
- Note visible mesh update delay. Smoothness is not the only criterion.
- Disable incompatible performance mods for first isolated tests.
- **No measurements have been collected. No claim of a performance improvement is warranted.**
